# 屋台の値下げ合戦（yatai-negasen）

縁日のとなりの屋台と10日間、毎日「そのまま」か「値下げ」かを同時に選び、10日たったら相手の性格を当てる1日5軒のゲーム。正解したら、その相手からいちばん多く点を取れるやり方も選ぶ。点の表は囚人のジレンマ（3・5・0・1）。

遊ぶ: <https://satou-aaaaa.github.io/yatai-negasen/>

- 点の表と相手の性格（しっぺ返し・根に持つ など）は、R. Axelrod のコンピューターの作戦の大会（1980年）と、ずんだもん解説「値下げ競争が止まらない理由」（YouTube 小江戸ゲーム部）の8つの作戦から。出典は Axelrod 本人の解説 <https://websites.umich.edu/~axe/research/Software/CC/ECHome/ECCitationClassic.html> 。
- 点はゲームの中だけのもので、お金とは関係ありません。屋台はすべて架空です。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各軒の○×の並びが、選んだサービス（X・LINE など）に渡ります。

作業の決まりは [AGENTS.md](AGENTS.md)。
